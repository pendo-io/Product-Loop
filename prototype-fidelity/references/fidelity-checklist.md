# Fidelity Checklist

Run before delivering. Go region by region.

## Layout
- [ ] Overall structure matches (sidebar width, header height, content padding)
- [ ] Column proportions match
- [ ] No elements added that aren't in the screenshot
- [ ] No elements removed that are in the screenshot

## Colors
- [ ] Page, sidebar, header backgrounds match
- [ ] All text colors match (primary, secondary, muted)
- [ ] All border colors match
- [ ] All button fills match
- [ ] All badge colors (bg AND text) match
- [ ] Icon colors match

## Typography
- [ ] Font families match (or fallback noted)
- [ ] Font sizes correct
- [ ] Font weights match
- [ ] Letter-spacing on section labels present

## Spacing
- [ ] Page outer padding matches
- [ ] Card inner padding matches
- [ ] Gap between nav items matches
- [ ] Gap between sections matches

## Components
- [ ] Every button: style, size, label, icon
- [ ] Every input/dropdown: size and style
- [ ] Table columns: same count, headers, alignment
- [ ] All badges and pills
- [ ] Navigation items: labels, order, section groupings, active state
- [ ] Border radius correct per element type
- [ ] Shadows present where shown, absent where not

## States
- [ ] Exact state shown reproduced (do not substitute a "better" state)

## Deviations log

Fill this in during the build. Add one row for each intentional deviation from the
screenshot (a user instruction, a font that couldn't load, an icon substituted, an
accessibility fix the user approved). For a description build, log deviations from the
description. If there are none, write "None" under the table.

| What | Where | Why |
|---|---|---|
| [what differs from the screenshot] | [region or element] | [instruction, constraint, or approved fix] |

Report the log with the delivered prototype.
